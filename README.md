# POO-Seguimiento-Roadmap-Java

Este repositorio contiene el seguimiento del curso de Programación Orientada a Objetos, utilizando como referencia el Roadmap de Java.

El objetivo del proyecto es practicar diferentes temas de Java mediante paquetes y clases organizadas por contenido.

## Temas trabajados

- Básicos de programación orientada a objetos
- Encapsulamiento
- Enums
- Manejo de excepciones
- Herencia
- Bloques de inicialización
- Clase principal
- Modificadores de acceso
- Sobrecarga y sobrescritura de métodos
- Organización por paquetes
- Métodos con parámetros
- Conversión de tipos
